Desativa as notificações do Telegram globalmente. Use este comando para desabilitar notificações quando as tarefas forem concluídas em qualquer projeto.

Execute o seguinte comando no terminal (macOS):

```bash
rm -f SEU_CAMINHO/botMessage/.telegram_enabled
printf '\033[33m🔕 Notificações do Telegram DESATIVADAS\033[0m\n'
```

Após executar, confirme ao usuário que as notificações foram desativadas.
