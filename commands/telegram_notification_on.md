Ativa as notificações do Telegram globalmente. Use este comando para habilitar notificações quando as tarefas forem concluídas em qualquer projeto.

Execute o seguinte comando no terminal (macOS):

```bash
touch /Users/thiagoeugenio/development/botMessage/.telegram_enabled
printf '\033[32m✅ Notificações do Telegram ATIVADAS\033[0m\n'
```

Após executar, confirme ao usuário que as notificações foram ativadas.
